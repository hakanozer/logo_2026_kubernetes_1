Dış HTTP girişi

m08 · Ingress, controller, routing ve TLS

Gateway’i `logo.local` hostname’inden Traefik Ingress’e yönlendirin ve kendinden imzalı TLS ile HTTPS isteğini görün.

1. Hedef ve çıktı

IngressClass varlığını kontrol edin, sertifika üretin, TLS Secret ve Ingress uygulayın, local host eşlemesini yapıp HTTPS üzerinden `/inventory/list` çağırın. Çıktı: Gateway’e TLS ile ulaşılan host routing ve sertifika zinciri/uyarı sınırının anlaşılması.

2. Kurumsal katkı

Ingress merkezi HTTP(S) host/path routing, TLS termination ve politika uygulama alanı sağlar; her Pod için NodePort açma ihtiyacını azaltır. Sertifika lifecycle’ı, host routing ve load balancing standartlaşır. Controller ve external LB olmadığında manifest trafik almaz; TLS secret üretmek sertifika güven zinciri kurmaz. Doğru ingress katmanı dışarıya açık endpoint sayısını ve manuel proxy konfigürasyonunu azaltır.

3. Kavram

Ingress API kaynağı trafik yönlendirme niyetini bildirir; Ingress Controller kuralları izleyip çalışan proxy yapılandırmasına dönüştürür. IngressClass controller uygulamasını seçer. TLS Secret sertifika/özel anahtar eşleşmesini saklar. Routing kuralı host, path türü/prefix ve backend Service port’unu eşler. Benzetme: Ingress yön levhası, Controller levhaya göre trafiği yönlendiren görevli. Ingress API tek başına proxy değildir; Gateway API daha kapsamlı trafik kuralları için gelişen ayrı bir API’dir.

4. Proje senaryosu

Mevcut referans Gateway Service’i ClusterIP’tir; yerel erişim port-forward ile yapılır. Eğitim Ingress’i `logo.local` hostunu `api-gateway:8080` servisine yönlendirir. Rancher Desktop kurulumlarında Traefik çoğunlukla hazır gelir; sınıfta kullanmadan önce kontrol edin. Manifest `logo-local-tls` Secret’ını bekler.

5. Uygulama

  1. IngressClass, controller Pod’ları ve host port eşlemesini kontrol edin. Traefik erişilemiyorsa `port-forward` kullanın; canlı Ingress çalışıyormuş gibi göstermeyin, diyagram ve YAML üzerinden anlatın.
  2. `logo.local` için kısa ömürlü, kendinden imzalı sertifika oluşturun; sertifika ve anahtardan `logo-ms` namespace’inde TLS Secret üretin. Ingress’i uygulayıp event’leri, controller loglarını ve host/path yönlendirmesini kontrol edin.
  3. `curl -k` yalnızca yerel demo sertifika güvenini atlar; üretimde istemciler güvenilir sertifika zincirini ve hostname’i doğrulamalıdır.

6. YAML satır satır açıklaması

apiVersion: networking.k8s.io/v1 stable Ingress API; `metadata.namespace` must match Service/Secret namespace; `spec.ingressClassName` selects controller. Rule `host` matches HTTP Host; `pathType: Prefix` matches path prefix; backend `service.name` is DNS target; `service.port.number` is Service port, not containerPort. `tls.hosts` and `secretName` bind certificate. Controller’a özgü annotation’lar taşınabilir değildir; ilgili controller belgelerine göre kullanılmalıdır.

8. Eğitmen notları

Say: “Ingress is configuration; controller is the running proxy.” Show: request failing before controller/host rule and succeeding after; certificate subject and issuer. Duration: 40 min. Stop: “Is a self-signed certificate production TLS?” No.

Rancher Desktop's controller/port mapping can vary; confirm it before class. If unavailable: use diagram + YAML + `kubectl port-forward`, note that it is fallback not an Ingress test. Don't teach `-k` as normal client configuration.

9. Katılımcı alıştırması

Add a second path `/orders` routed to `order-service:8081`, then verify `/orders/orderList` through the same hostname and TLS. Hint: path rewrites are not automatic; gateway behavior and path sent to backend matter.

Verify `kubectl describe ingress`, controller logs and `curl -k --resolve ...`.

Show solution

Add a Prefix path `/orders` to Service order-service port 8081. Ingress sends the original path to Order; Order controller base path is `/order`, so `/orders/orderList` does not automatically become `/order/orderList`. Prefer route `/order` or use a controller-specific rewrite only after explicitly configuring/validating its annotation.

10. Hata ve çözümleri

  • 404 default backend: host/path/class didn't match.
  • 503: backend service has no ready endpoints or port mismatch.
  • TLS secret not found: namespace/name mismatch, type must kubernetes.io/tls.
  • DNS/connection timeout: hosts entry resolves but controller not listening on that port.

11. Üretimde fark

Üretimde kurumsal/ACME sertifika yaşam döngüsü, özel anahtar koruması, uygun HSTS/security header’ları, WAF/rate limit, birden fazla controller replikası ve LoadBalancer sağlık kontrolleri tasarlanır. Controller güncel ve izlenebilir olmalıdır. Tek node self-signed testi sertifika yönetimini veya dış LB yüksek erişilebilirliğini kanıtlamaz.

12. Modül özeti ve kontrol listesi

  • Ingress resource vs controller distinguished.
  • TLS Secret and hostname route verified.
  • Controller/host port checked on this cluster.
  • `-k` limitation stated.
