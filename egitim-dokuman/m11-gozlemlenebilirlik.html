m11 · Logs, metrics, events, Prometheus/Grafana ve merkezi log

Üç sinyali (logs, metrics, events) kullanarak incident teşhisi yapın; application metrics ve node-level log collection farkını kurun.

1. Hedef ve çıktı

Pod logs, previous container logs, events ve metrics’i toplayın; metrics-server için `top` deneyin. Actuator + Micrometer/Prometheus endpoint prerequisite’ini görüp Prometheus/Grafana’yı Helm ile kurma akışını inceleyin. Fluent Bit DaemonSet ile container stdout’u Elasticsearch’e gönderme örneğini yapılandırın; Kibana’da index arayın.

2. Kurumsal katkı

Gözlemlenebilirlik, sorunu fark etme ve hizmeti geri kazanma süresini kısaltır. Log’lar olayların ayrıntısını, metric’ler eğilimleri ve SLO’ları, trace’ler (dağıtık izler) servisler arası istek akışını gösterir; Kubernetes event’leri zamanlama ve kontrol düzlemi eylemlerini açıklar. Merkezi saklama ve dashboard’lar nöbet müdahalesi ile denetimi destekler. Her isteği loglamak, yüksek kardinaliteli etiketler kullanmak ve senkron appender’a bağlanmak maliyeti artırıp kesintiyi ağırlaştırabilir.

3. Kavram

Logs are discrete records; metrics are numeric time series; events are cluster state-change objects; traces follow a request across boundaries. Prometheus scrapes `/metrics` endpoints; Grafana queries data sources and visualizes/alerts. Fluent Bit/Filebeat node agents read container logs and forward them centrally. Kubernetes’te stdout/stderr, platformun toplaması için tercih edilen container log akışıdır. Analogy: logs diary, metrics dashboard, events activity ledger, trace route map.

4. Proje senaryosu

Compose includes Logstash and Elasticsearch/Kibana; current K8s manifests omit Logstash and Fluent Bit. Inventory Logback appender sends directly to hardcoded `localhost:9200/_bulk`; Pod içindeki `localhost`, Elasticsearch’i değil aynı Pod’u gösterir. Mevcut POM dosyalarında Spring Boot Actuator ve Prometheus registry bağımlılıkları bulunmuyor. m11 YAML provides Fluent Bit DaemonSet/ConfigMap; Helm chart kurulumu için chart/image registry ağına erişim veya kurum içi mirror gerekir.

5. Adım adım uygulama

  1. Use `describe`, `logs`, events and `top` for one known healthy/broken Pod; timestamp and namespace.
  2. Verify Actuator not present in current binaries. After approved dependency/config and rebuilt images, curl `/actuator/health` and `/actuator/prometheus` from cluster.
  3. Add Prometheus chart repository and install release in dedicated namespace or logo-ms with explicit values; add Grafana and dashboard only after scrape path verified.
  4. Apply Fluent Bit config and DaemonSet; confirm one agent Pod per node, input parser and Elasticsearch output connectivity.
  5. Query Kibana index. Avoid duplicate app direct-to-ES and node agent paths unless deduplication/index strategy is intentional.

6. YAML açıklaması

Fluent Bit ConfigMap supplies inputs/parsers/outputs; ServiceAccount and ClusterRole allow read access to Pod metadata; DaemonSet selector/template labels connect owner and Pod; tolerations may permit system nodes; volumes mount host `/var/log/containers` read-only. Elasticsearch output `Host` uses cluster Service DNS, not localhost. Prometheus operator CRDs and scrape annotations/ServiceMonitor need compatible chart configuration. Avoid putting Elasticsearch passwords in ConfigMap.

7. macOS / Windows farkları

CLI commands same, but Shell quoting of Helm values varies. Prefer a checked-in values YAML file instead of many inline `--set` strings. Rancher Desktop single node gives one DaemonSet replica; don't present as multi-node fleet evidence. Browser Kibana access use port-forward or an approved Ingress; no direct host port is guaranteed.

8. Eğitmen notları

Say: “Logs show an event; metrics show its scale; event tells what the platform attempted.” Show: `--previous` after crash, HPA metric relation, Fluent Bit DaemonSet one per node. Duration: 55 min. Stop: “Does a green dashboard prove user-visible SLO?” No, measure service-level behavior.

Actuator is a proposed code diff, not currently available. Don't accidentally keep Inventory's direct appender pointing at localhost. The Helm chart downloads need Internet/artifact mirror and 8+ GB memory. Alternative if resource constraints: render manifests and explain dashboards via diagram.

9. Katılımcı alıştırması

Induce a controlled invalid Order Redis host in lab, capture first failed logs and events, restore value. Then locate one log line in Elasticsearch/Kibana through Fluent Bit, and a metric in Prometheus only if Actuator/exporter is included.

Verify `kubectl logs`, `kubectl get events`, `kubectl get ds`, `kubectl get pods -l app=fluent-bit`, and query endpoint.

Show solution

Order startup logs/event reveal DNS failure; restore ConfigMap and restart deployment. Fluent Bit DaemonSet should run on the node and output logs to configured index. Metrics endpoint remains unavailable until Actuator plus Prometheus registry dependency is approved, added and image rebuilt. Never interpret the existing logback direct output as functioning in K8s.

10. Hata ve çözümleri

  • Fluent Bit no logs: container path, parser, RBAC, mount and tail DB state.
  • Elasticsearch connect failure: Service DNS/port, endpoint ready, index/auth and network policy.
  • Prometheus target down: endpoint path/port/service monitor selector or missing Actuator registry.
  • `kubectl top` fails: metrics-server/API availability; app Prometheus metrics are a separate pipeline.

11. Üretimde fark

Üretim gözlemlenebilirliği retention/ILM, tenant ayrımı, PII redaksiyonu, buffering/backpressure, alarm sahipliği, SLO/error budget, trace context, cardinality bütçesi, kaynak yükü ve erişim denetimini kapsar. Filebeat/Fluent Bit alternatif log taşıyıcılardır; tek standart seçin. Prometheus HA/federation/remote storage ve Grafana auth ayrıca tasarlanır. Tek node fleet ölçeğini kanıtlamaz.

12. Modül özeti ve kontrol listesi

  • logs/metrics/events/traces distinguished.
  • Logs/events/top used with correct `--previous` context.
  • Application metrics prerequisite disclosed.
  • Fluent Bit DaemonSet vs app logback output understood.
  • Prometheus/Grafana resource/network constraint stated.
